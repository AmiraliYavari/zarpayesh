## معرفی پروژه

**زرپایش** یک سامانه فارسی برای پایش بازارهای مالی ایران است که با هدف ارائه اطلاعات دقیق، قابل بررسی و کاربردی درباره نرخ ارز، طلا و سکه توسعه داده شده است.

این سامانه علاوه بر نمایش قیمت‌های بازار آزاد، امکاناتی مانند بررسی تاریخچه واقعی معاملات، نمودارهای تحلیلی، تبدیل دارایی‌ها، محاسبه ارزش تقریبی طلا و سکه و تنظیم هشدارهای قیمتی را در اختیار کاربران قرار می‌دهد.

زرپایش از داده‌های عمومی TGJU استفاده می‌کند و میان زمان دریافت اطلاعات و زمان اعلام‌شده توسط منبع تفاوت قائل می‌شود تا وضعیت داده‌ها شفاف‌تر باشد.

## امکانات اصلی

### پایش بازار

- نمایش نرخ ارز، طلا و سکه در بازار آزاد.
- تفکیک زمان دریافت اطلاعات از زمان اعلام‌شده توسط منبع.
- جستجو میان دارایی‌ها و فیلتر بر اساس منطقه.
- نمایش وضعیت کیفیت و تازگی داده‌ها.
- پشتیبانی از نرخ انس جهانی و دارایی‌های ارزی.

### تاریخچه و نمودارها

- نمایش تاریخچه واقعی قیمت‌ها در بازه‌های درون‌روزی و روزانه.
- نمودار خطی و شمعی (Candlestick).
- پشتیبانی از بازه‌های زمانی یک ساعت، یک روز، یک هفته، یک ماه، سه ماه، شش ماه و یک سال.
- بررسی دقیق هر نمونه داده با لمس، ماوس یا صفحه‌کلید.
- استفاده از داده‌های واقعی OHLC یا تجمیع نمونه‌های ثبت‌شده.
- حذف داده‌های نامعتبر، تکراری و مربوط به آینده.
- نمایش پیام مشخص در صورت نبود اطلاعات کافی برای یک بازه زمانی.

### مبدل دارایی‌ها

- تبدیل میان ارزها، طلا و سایر دارایی‌های پشتیبانی‌شده.
- تبدیل ریال و تومان.
- پشتیبانی از اعداد فارسی و عربی در ورودی‌ها.
- تبدیل قیمت انس جهانی از دلار به ریال با استفاده از نرخ دلار.
- نمایش محاسبات بر اساس نرخ‌های دریافتی از منبع.

### محاسبات طلا و سکه

- برآورد مبلغ فاکتور خرید طلا.
- دریافت درصدهای موردنظر کاربر برای محاسبه.
- محاسبه ارزش تقریبی بر اساس نرخ‌های بازار.
- برآورد حباب قیمتی سکه.

> محاسبات این بخش جنبه برآوردی دارند و جایگزین فاکتور رسمی فروشنده یا محاسبات قانونی مالیاتی نیستند.

### سیستم هشدار قیمت

- تعریف هشدار یک‌باره برای قیمت دارایی‌ها.
- ذخیره تنظیمات هشدار در `localStorage`.
- نمایش اعلان داخل صفحه.
- پشتیبانی از صدای اختیاری برای هشدارها.
- بررسی شرایط هشدار هنگام باز بودن وب‌سایت.

> هشدارهای وب‌سایت به اجرای فعال صفحه وابسته هستند و در زمان بسته بودن سایت یا مرورگر تضمینی برای ارسال ندارند.

### رابط کاربری و دسترس‌پذیری

- رابط کاربری کاملاً فارسی و واکنش‌گرا.
- استفاده از فونت متغیر Vazirmatn به‌صورت محلی با مجوز OFL.
- نمایش ارقام با عرض یکسان برای خوانایی بهتر.
- پشتیبانی از فوکوس صفحه‌کلید.
- رعایت تنظیمات کاهش حرکت (Reduced Motion).
- طراحی سازگار با نمایشگرهای دسکتاپ و موبایل.

## API و اعتبارسنجی داده‌ها

### دریافت قیمت‌های بازار

`GET /api/market`

این مسیر اطلاعات بازار را از جداول عمومی TGJU دریافت می‌کند.

فیلدهای مهم:

| فیلد | توضیح |
|---|---|
| `dataQuality` | وضعیت کیفیت داده‌های دریافتی |
| `observedAt` | زمان دریافت اطلاعات |
| `updatedAt` | زمان آخرین نرخ اعلام‌شده |

نکات مربوط به داده‌ها:

- داده‌های موقت کش ممکن است نمایش داده شوند.
- داده‌های نمونه و نرخ‌های تخمینی در رابط کاربری نمایش داده نمی‌شوند.
- قیمت انس جهانی بر حسب دلار است.
- سایر قیمت‌ها در API بر حسب ریال ارائه می‌شوند.
- نرخ دینار عراق به ازای یک دینار محاسبه می‌شود.

### دریافت تاریخچه قیمت

`GET /api/history?symbol=price_dollar_rl&range=1D`

تاریخچه قیمت‌ها از منابع عمومی نمودار TGJU دریافت می‌شود.

منابع داده بر اساس بازه زمانی:

| بازه | منبع |
|---|---|
| `1D` | آرایه عمومی نمودار صفحه نماد |
| `1W` | جدول تاریخچه روزانه |
| `1M` | جدول تاریخچه روزانه |
| `3M` | جدول تاریخچه روزانه |
| `6M` | جدول تاریخچه روزانه |
| `1Y` | جدول تاریخچه روزانه |

ملاحظات فنی:

- مرتب‌سازی داده‌ها بر اساس زمان.
- حذف نمونه‌های تکراری.
- کنار گذاشتن نقاط نامعتبر و مربوط به آینده.
- تولید نمودار شمعی از اطلاعات واقعی OHLC یا تجمیع نمونه‌های واقعی.
- عدم تولید نوسان یا داده مصنوعی.
- نمایش پیام مشخص در صورت نبود داده کافی در بازه‌های کوتاه.

به دلیل تعطیلی بازار یا تأخیر در انتشار اطلاعات توسط منبع، ممکن است آخرین داده موجود مربوط به آخرین روز معاملاتی باشد.

### شفافیت اطلاعات

زرپایش از نمایش اطلاعات فاقد منبع معتبر خودداری می‌کند.

مواردی مانند نرخ سنا و نیما، شاخص ترس و طمع، آمار حجم معاملات و تحلیل‌های خبری تا زمانی که منبع مشخص و قابل اتکایی برای آن‌ها وجود نداشته باشد، ارائه نمی‌شوند.

همچنین محاسبات مبدل و فاکتور شامل کارمزد معامله نیستند و نرخ قانونی مالیات یا سود فروشنده را به‌صورت پیش‌فرض در نظر نمی‌گیرند.

## استقرار و انتشار

### وب‌سایت

مخزن پروژه به پروژه‌ای در Vercel با نام `zarpayesh` متصل است.

- شاخه `main` مرجع انتشار نسخه اصلی است.
- تغییرات ثبت‌شده در این شاخه از طریق فرایند استقرار Vercel منتشر می‌شوند.

**نشانی وب‌سایت:** [zarpayesh-five.vercel.app](https://zarpayesh-five.vercel.app)

### ربات تلگرام

فرایند انتشار ربات از طریق GitHub Actions و زیرساخت TG Cloud انجام می‌شود.

ویژگی‌های این فرایند:

- انتشار خودکار ماژول‌های ربات پس از دریافت وضعیت TG Cloud.
- اجرای Migrationهای افزایشی پایگاه داده.
- اجرای زمان‌بندی‌شده هر پنج دقیقه از طریق GitHub Actions.
- عدم وابستگی به روشن بودن رایانه توسعه‌دهنده.

**نکات امنیتی:**

- مقدار `TGCLOUD_TOKEN` باید صرفاً در GitHub Actions Secrets نگهداری شود.
- فایل‌های `.env*` نباید وارد مخزن Git شوند.
- پوشه `.tgcloud/` نباید در مخزن عمومی قرار بگیرد.
- اطلاعات محرمانه نباید در کد منبع یا فایل‌های قابل انتشار قرار داده شوند.

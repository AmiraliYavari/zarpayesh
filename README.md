## معرفی پروژه

**زرپایش (Zarpayesh)** یک سامانه فارسی برای پایش و بررسی بازارهای مالی ایران است که با هدف ارائه اطلاعات دقیق، قابل بررسی و کاربردی درباره نرخ ارز، طلا و سکه توسعه داده شده است.

این پلتفرم علاوه بر نمایش قیمت‌های بازار آزاد، ابزارهای مختلفی برای بررسی تاریخچه قیمت‌ها، مشاهده نمودارهای تحلیلی، تبدیل دارایی‌ها، محاسبه ارزش تقریبی طلا و سکه و تعریف هشدارهای قیمتی در اختیار کاربران قرار می‌دهد.

زرپایش از داده‌های عمومی TGJU استفاده می‌کند و با تفکیک زمان دریافت اطلاعات از زمان اعلام‌شده توسط منبع، تلاش می‌کند وضعیت و اعتبار داده‌های بازار را به شکل شفاف‌تری نمایش دهد.

این پروژه شامل دو بخش اصلی است:

- وب‌سایت پایش بازار با رابط کاربری فارسی و واکنش‌گرا.
- ربات تلگرام برای دریافت گزارش‌ها، نمودارها و هشدارهای بازار.

## امکانات و قابلیت‌ها

### ۱. پایش بازار

- نمایش نرخ ارز، طلا و سکه در بازار آزاد.
- تفکیک زمان دریافت داده از زمان اعلام‌شده توسط منبع.
- جستجو میان دارایی‌های مختلف.
- فیلتر اطلاعات بر اساس منطقه.
- نمایش وضعیت کیفیت و تازگی داده‌ها.
- پشتیبانی از قیمت انس جهانی و دارایی‌های ارزی.

### ۲. تاریخچه قیمت و نمودارها

- نمایش تاریخچه واقعی قیمت‌ها در بازه‌های درون‌روزی و روزانه.
- پشتیبانی از نمودارهای خطی (Line Chart) و شمعی (Candlestick).
- امکان بررسی بازه‌های زمانی از یک ساعت تا یک سال.
- بررسی اطلاعات هر نمونه با لمس، ماوس یا صفحه‌کلید.
- استفاده از اطلاعات واقعی OHLC برای نمودارهای شمعی.
- تجمیع نمونه‌های واقعی برای ساخت اطلاعات باز، بسته، سقف و کف قیمت.
- مرتب‌سازی داده‌ها بر اساس زمان.
- حذف نمونه‌های تکراری، نامعتبر و مربوط به آینده.
- نمایش پیام مشخص در صورت نبود اطلاعات کافی برای یک بازه زمانی.

### ۳. مبدل دارایی‌ها

- تبدیل میان دارایی‌های پشتیبانی‌شده.
- تبدیل ریال و تومان.
- پشتیبانی از اعداد فارسی و عربی در ورودی‌ها.
- تبدیل قیمت انس جهانی از دلار به ریال با استفاده از نرخ دلار.
- محاسبه بر اساس نرخ‌های دریافتی از منبع داده.

### ۴. محاسبات طلا و سکه

- برآورد مبلغ فاکتور خرید طلا.
- امکان وارد کردن درصدهای محاسباتی توسط کاربر.
- محاسبه ارزش تقریبی طلا بر اساس نرخ بازار.
- برآورد حباب قیمتی سکه.

محاسبات این بخش جنبه برآوردی دارند و جایگزین فاکتور رسمی فروشنده یا محاسبات قانونی مالیاتی نیستند.

### ۵. سیستم هشدار قیمت

- تعریف هشدار یک‌باره برای قیمت دارایی‌ها.
- ذخیره تنظیمات هشدار در `localStorage`.
- نمایش اعلان در محیط وب‌سایت.
- پشتیبانی از صدای اختیاری هشدار.
- بررسی شرایط هشدار هنگام باز بودن وب‌سایت.

هشدارهای وب‌سایت به اجرای فعال صفحه وابسته هستند و در زمان بسته بودن سایت یا مرورگر، ارسال آن‌ها تضمین نمی‌شود.

### ۶. رابط کاربری و دسترس‌پذیری

- رابط کاربری کاملاً فارسی.
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل.
- استفاده از فونت متغیر Vazirmatn به‌صورت محلی با مجوز OFL.
- نمایش ارقام با عرض یکسان برای خوانایی بهتر.
- پشتیبانی از فوکوس صفحه‌کلید.
- رعایت تنظیمات کاهش حرکت (Reduced Motion).
- بهینه‌سازی تجربه استفاده در نمایشگرهای مختلف.

## API و ساختار داده‌ها

زرپایش برای دریافت اطلاعات بازار و تاریخچه قیمت‌ها از APIهای اختصاصی استفاده می‌کند.

### دریافت اطلاعات بازار

**Endpoint:**

```http
GET /api/market
```

این مسیر اطلاعات قیمت‌ها را از جداول عمومی TGJU دریافت می‌کند.

فیلدهای مهم:

| فیلد | توضیح |
|---|---|
| `dataQuality` | وضعیت کیفیت داده‌های دریافتی |
| `observedAt` | زمان دریافت اطلاعات |
| `updatedAt` | زمان آخرین نرخ اعلام‌شده توسط منبع |

### ملاحظات داده‌های بازار

- داده‌های موقت کش ممکن است نمایش داده شوند.
- داده‌های نمونه و نرخ‌های تخمینی در رابط کاربری نمایش داده نمی‌شوند.
- قیمت انس جهانی بر حسب دلار است.
- سایر قیمت‌ها در API بر حسب ریال ارائه می‌شوند.
- نرخ دینار عراق به ازای یک دینار محاسبه می‌شود.

### دریافت تاریخچه قیمت

**Endpoint:**

```http
GET /api/history?symbol=price_dollar_rl&range=1D
```

این مسیر تاریخچه قیمت را بر اساس نماد و بازه زمانی درخواست‌شده دریافت می‌کند.

### منابع تاریخچه

| بازه زمانی | منبع اطلاعات |
|---|---|
| `1D` | آرایه عمومی نمودار صفحه نماد |
| `1W` | جدول تاریخچه روزانه |
| `1M` | جدول تاریخچه روزانه |
| `3M` | جدول تاریخچه روزانه |
| `6M` | جدول تاریخچه روزانه |
| `1Y` | جدول تاریخچه روزانه |

### پردازش و اعتبارسنجی تاریخچه

در فرایند پردازش تاریخچه:

- داده‌ها بر اساس زمان مرتب می‌شوند.
- نمونه‌های تکراری حذف می‌شوند.
- نقاط نامعتبر کنار گذاشته می‌شوند.
- داده‌های مربوط به آینده حذف می‌شوند.
- نمودار شمعی از اطلاعات واقعی OHLC یا تجمیع نمونه‌های واقعی ساخته می‌شود.
- هیچ نوسان مصنوعی یا داده ساختگی برای تکمیل نمودار تولید نمی‌شود.
- در صورت نبود داده کافی برای بازه‌های کوتاه، پیام مشخصی به کاربر نمایش داده می‌شود.

به دلیل تعطیلی بازار یا تأخیر در انتشار اطلاعات توسط منبع، ممکن است آخرین داده موجود مربوط به آخرین روز معاملاتی باشد.

### شفافیت و اعتبار اطلاعات

زرپایش از نمایش اطلاعات فاقد منبع مشخص خودداری می‌کند.

مواردی مانند نرخ سنا و نیما، شاخص ترس و طمع، آمار حجم معاملات و تحلیل‌های خبری تا زمانی که منبع مشخص و قابل اتکایی برای آن‌ها وجود نداشته باشد، در سامانه نمایش داده نمی‌شوند.

همچنین محاسبات مبدل و فاکتور شامل کارمزد معامله نیستند و نرخ قانونی مالیات یا سود فروشنده را به‌صورت پیش‌فرض در نظر نمی‌گیرند.

کاربران باید درصدهای محاسباتی را مطابق فاکتور واقعی خود وارد کنند.

## راه‌اندازی و توسعه

### پیش‌نیازها

- Node.js
- npm
- Git

### دریافت پروژه

```bash
git clone https://github.com/MRGhust/zarpayesh.git
cd zarpayesh
```

### نصب وابستگی‌های وب‌سایت

```bash
npm ci
```

### اجرای محیط توسعه

```bash
npm run dev
```

### اجرای آزمون‌های بازار

```bash
npm run test:market
```

### نصب وابستگی‌های ربات

```bash
npm --prefix az_be_ma_mabot ci
```

### اجرای آزمون‌های ربات

```bash
npm --prefix az_be_ma_mabot test
```

### ساخت نسخه نهایی

```bash
npm run build
```

### اجرای نسخه نهایی

```bash
npm start
```

## استقرار و انتشار

### وب‌سایت

مخزن پروژه به یک پروژه در Vercel با نام `zarpayesh` متصل است.

- شاخه `main` مرجع انتشار نسخه اصلی است.
- تغییرات ثبت‌شده در این شاخه از طریق فرایند استقرار Vercel منتشر می‌شوند.

**نشانی وب‌سایت:**

[https://zarpayesh-five.vercel.app](https://zarpayesh-five.vercel.app)

### ربات تلگرام

فرایند انتشار ربات از طریق GitHub Actions و زیرساخت TG Cloud انجام می‌شود.

ویژگی‌های این فرایند:

- دریافت وضعیت TG Cloud پیش از انتشار.
- انتشار خودکار ماژول‌های ربات.
- اعمال Migrationهای افزایشی پایگاه داده.
- اجرای زمان‌بندی‌شده هر پنج دقیقه از طریق GitHub Actions.
- عدم وابستگی به روشن بودن رایانه توسعه‌دهنده.

### ملاحظات امنیتی

- مقدار `TGCLOUD_TOKEN` باید فقط در GitHub Actions Secrets نگهداری شود.
- فایل‌های `.env*` نباید وارد مخزن Git شوند.
- پوشه `.tgcloud/` نباید در مخزن عمومی قرار بگیرد.
- اطلاعات محرمانه نباید در کد منبع یا فایل‌های قابل انتشار ذخیره شوند.
